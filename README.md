# QuickNotes

QuickNotes is a simple web application that allows users to create, organize, search, and delete notes. Each note can be assigned a category, and notes are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add new notes
- Choose a category for each note
- Display notes as cards
- Delete notes
- Search notes by text
- Validate empty notes
- Limit notes to 200 characters
- Display the number of notes
- Save notes using localStorage
- Responsive layout for smaller screens
